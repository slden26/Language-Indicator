# Language Indicator (v2)

Легкая утилита для визуального контроля текущего языка ввода. Больше не нужно коситься в угол панели задач.

### Основные возможности:
* **Визуальные флаги**: Текущий язык (RU, UA, EN) отображается аккуратной иконкой.
* **Свободное перемещение**: Хватай мышкой и ставь в любое место экрана.
* **Закрепление**: Через меню можно зафиксировать флаг, чтобы он не мешал случайно.
* **Автозагрузка**: Включается одной галочкой в меню (создает ярлык в папке Startup).
* **Всегда сверху**: Флаг перекрывает другие окна, но не мешает работе.

### Инструкция:
1. Запустите `Indicator.exe`.
2. Перетащите флаг туда, где вам удобно его видеть.
3. Нажмите правой кнопкой мыши для вызова настроек (Закрепить / Автозапуск).
4. Чтобы закрыть программу, нажмите на маленький "×" в углу флага или выберите "Выход" в меню.

### Техническая часть:
Написано на **AutoHotkey v2**. Все ресурсы (флаги и иконка) вшиты в исполнительный файл.
